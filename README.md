# Лабораторная работа №2 — Работа с данными и введение в машинное обучение на Python

## Описание

Лабораторная работа посвящена практическому освоению базовых библиотек для обработки данных и машинного обучения на Python:

- **NumPy** — векторизованные вычисления над массивами;
- **Pandas** — загрузка, агрегация и анализ табличных данных;
- **Matplotlib** — визуализация результатов;
- **scikit-learn** — построение и оценка моделей машинного обучения (регрессия и классификация).

В работе решаются задачи на трёх наборах данных: **Титаник**, синтетический датасет **«Стоимость квартиры»** (регрессия) и синтетический датасет **«Кредитный скоринг»** (классификация).

## Ключевые выводы

- **NumPy** позволяет решать задачи обработки массивов векторно, без явных циклов, за счёт встроенных функций (`cumsum`, `diff`, `repeat`, `argmin`).
- **Синтетические датасеты Б и В не содержат пропусков**; целевая переменная `price` близка к нормальному распределению, а классы `default` имеют умеренный дисбаланс (~2:1).
- **Для линейно-порожденных данных** (датасет Б) обычная `LinearRegression` показывает лучшее качество, чем MLP, поскольку данные не содержат нелинейных зависимостей, и сложная модель оказывается избыточной.
- **L1-регуляризация** (Lasso) выполняет отбор признаков, обнуляя малозначимые коэффициенты, а **L2** (Ridge) плавно сжимает все веса — при `alpha → ∞` коэффициенты Ridge стремятся к нулю.
- **При дисбалансе классов** одной метрики `accuracy` недостаточно: `DummyClassifier` показывает более высокую `accuracy`, чем MLP, но полностью «пропускает» класс дефолтов. Для оценки качества классификации необходимы `precision`, `recall` и `F1-score` по каждому классу.
- **`StandardScaler` критичен для MLP**, так как нейросети чувствительны к масштабу признаков — немасштабированные данные замедляют и дестабилизируют обучение.
